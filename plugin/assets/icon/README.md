# App icon

New logo (owner, 2026-11-07): "A + lying B / p bowl" over "SURD" in Inter Bold outlines, red #D23C42 on the
dark #303134, rounded square (from the owner's logo package, AMPSURD-icon.svg).

`icon_1024.png` / `icon_256.png`: used by JUCE (ICON_BIG / ICON_SMALL) for the standalone app (.exe / .app) and
the window icon. `ampsurd.ico` (16-256 px, 7 sizes): the Windows installer (SetupIconFile).
The header logo in the plugin window: `assets/brand/ampsurd_logo.svg` (the red logo outlines).
